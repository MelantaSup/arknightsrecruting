# Калькулятор рекрутинга для игры Arknights
Калькулятор найма для Arknights, который избавляет от необходимости вручную перебирать десятки сочетаний тегов. Инструмент позволяет быстро отфильтровать доступные теги и мгновенно рассчитать все возможные комбинации гарантированного получения редких оперативников (4★–6★)

##Стек:
- HTML
- CSS
- JS
